Serious infrastructure. A happier place to run it.

Slipramp provides a home for all your Terraform, OpenTofu, Ansible and pyinfra workflows, executed in your Kubernetes clusters across the cloud and bare metal.

Explore on GitHub ↗ See how it works

GitOps-driven Workflows live in Git, executions are pinned to exact commits.

Kubernetes execution Controllers in each cluster reach out to the control plane, no inbound access needed.

Portable Actions Use your existing container images, scripts, and secrets management.

Multi-cluster, multi-cloud workflows

The Slipramp control plane

Centralized control plane handles tracking your Git repositories and scheduling executions in your clusters.

  1. 01

    Define Targets and Actions

    From basic scripts to first-class Terraform, OpenTofu, Ansible, and pyinfra workflows.

  2. 02

    Create a pinned Run

    Run workflows manually through the web UI or CLI, let your agent handle it through MCP, or automate runs with Git and scheduled triggers.

  3. 03

    Execute inside your clusters

    The local controller creates the Kubernetes Job and reports its status. The server never requires direct Kubernetes access.

Your data stays local.

Slipramp has no product analytics. Details about your Git repositories, runs, and executions do not leave your infrastructure.
