Slipramp Server and web were installed with one replica each.

The chart does not install PostgreSQL or S3-compatible storage. Confirm that the
configured database, bucket, OIDC provider, and referenced Secrets exist before
waiting for the Server readiness probe.

The Server Pod has service-account token automounting disabled and receives no
Kubernetes RBAC from this chart. Controllers require a separately installed
slipramp-controller chart in each execution Cluster.
