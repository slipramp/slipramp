# Product screenshots

Keep screenshots focused on the UI being explained and use descriptive,
kebab-case names such as `target-run-history.png`. Prefer PNG for interface
screenshots and WebP when a materially smaller file remains crisp at the
displayed size.

Reference screenshots from Markdown with descriptive alt text:

```md
![Run history for a target](../../../assets/screenshots/target-run-history.png)
```
